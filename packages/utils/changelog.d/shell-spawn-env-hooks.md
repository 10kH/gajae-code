### Fixed

- A project `.env` can no longer make bash tool commands run repository code. `BASH_ENV`/`ENV` and `ZDOTDIR` (shell startup files), `GIT_CONFIG_*`/`GIT_CONFIG_PARAMETERS`, `XDG_CONFIG_HOME`, `HOME`, `GIT_DIR`/`GIT_COMMON_DIR` (all of which can supply e.g. `core.fsmonitor`, which git executes during `git status`), and `GIT_EXTERNAL_DIFF`/`GIT_SSH`/`GIT_SSH_COMMAND` are dropped from the bash tool's isolated shell worker chain and interactive PTY sessions when the project declares them; a dropped `HOME` is replaced by the trusted account home. A value exported by the launching shell is kept, except when the project declares the same key with the same value or dynamically: provenance is then ambiguous and the variable is dropped, as for credentials. Python kernels keep their documented environment.
