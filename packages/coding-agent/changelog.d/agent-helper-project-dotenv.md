### Fixed

- The helpers GJC launches during a session now start from the same filtered environment as the bash tool. This covers the configured `completion.notifyCommand` after each turn, every browser the browser tool starts (puppeteer Chromium, an `app.path` executable, and an `app.browser: "chrome"` profile), and the `insane` web engine (python3 -> node -> Chromium). Previously a repository `.env` declaring `NODE_OPTIONS=--require ./x.js`, `LD_PRELOAD`, `PYTHONUSERBASE` or another hook variable ran repository code inside them. The notify command, puppeteer Chromium and the insane engine spread the process environment, into which the project `.env` is copied, so they leaked in the compiled binary too; the `app.path` and `chrome` profile launches inherited Bun's autoloaded environment (source and npm installs).
